# Deployment of Sentinel Connector for SecurityBridge Threat Detection for SAP via Content Hub

This ARM template deploys the **SecurityBridge Threat Detection for SAP** connector with the following components:

- Connector  
- Workbook  

---

## Deployment Steps

1. Log on to the **Azure Portal**.  
2. Navigate to **Microsoft Sentinel** and select your workspace.  
3. Go to **Content Hub**.  
4. Search for **SecurityBridge: SAP data to Microsoft Sentinel**.  
5. Click **Install**, then select **Create**.  
6. Follow the detailed steps described in the [SecurityBridge documentation](https://abap-experts.atlassian.net/wiki/spaces/SB/pages/4958945288/Connect+MS+Sentinel+via+the+REST+Push+API).
